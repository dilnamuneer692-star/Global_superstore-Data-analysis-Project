# Global_superstore-Data-analysis-Project

## 📌 Project Overview
This project focuses on analyzing Global Superstore sales data using Microsoft Power BI. The dashboard helps understand sales performance, profit, and business trends through interactive visualizations.

## 🎯 Objectives
- Analyze total sales and profit.
- Identify top-performing product categories.
- Compare sales across regions.
- Understand customer segment performance.
- Track business trends using interactive dashboards.

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Key Analysis
- Sales Analysis
- Profit Analysis
- Region-wise Performance
- Category-wise Sales
- Customer Segment Analysis

## 📁 Project File
- `Global Superstore_DILNA PROJECT -3.pbix` – Power BI project file.

## 📈 Dashboard
The dashboard provides visual insights into sales and profitability to support business decision-making.
